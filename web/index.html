占类决定取哪套用神、规则 1–10 怎么取类神。自动判定按问句关键词猜， 「钱包丢了」会被猜成求财、「另找合作方」会被猜成失物——猜错就整盘都错，这里看一眼，不对就在占类里改。

AI 解读 奇门为主·穿壬旁证　

⚙️ AI 设置（Provider / Key，仅存本机）
思考型模型（如 gemini-flash-latest）遇 500/超时，把它设 0 或调小往往能绕过
超时与重试（默认值一般够用；出现「生成超时」或「503 繁忙」时才需调）
多久没有新内容才算卡死。流式下这才是真超时——只要还在吐字就不会中断
遇 503/429/504 时按指数退避自动重试。填 0 即不重试（失败就直接报错， 有备用链的仍会接力）；留空用默认 3 次
思考型模型「思考+回答」共用此额度，调太小会截断答案
主 provider 反复失败后自动接力（需已填好该 provider 的必填项）

        

          自检会用当前配置发一次**最小**请求，把原始 HTTP 状态码与响应体原样列出——
          「暂时失败，重试中…」看不出是 500 还是断网，先跑这个，别猜。
