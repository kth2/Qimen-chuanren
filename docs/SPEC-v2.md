## 共同原则（规则 8–10）
- 每条规则两边各自定性：**奇门一侧**、**六壬一侧**，各得 ＋ / － / 〇（不定）。
- 两边同为 ＋ → 投 +1；同为 － → 投 −1；一正一负 → 记「混」，不投票；有一边不定 → 弃权。
- 冲突不消歧、不相加，原样记录（同 v1 计票表条件 3）。+1 只是关系分值，不等于吉或成功。

## 规则 7　应期融合·穿壬（不投是非票，只给应期日支）
**v2.1（kt 2026-10-28 定，取代 v2.0 的四法等权）：奇门为主，六壬决胜。**
1. 先取奇门应期融合法 v1（Qimen-pwa `YingQi.fusionV1`）的取支。
2. 奇门只取一支 → 照用。
3. 奇门取支多于一支（并列）→ 只留落在六壬三法取支里的那几支：末传之六合支、初传之六合支、三传中落日旬空之支。
   一支都不在 → 照奇门原样。
4. 飞盘无奇门融合法；六壬三法单用在回测里低于瞎猜，故飞盘弃权，不给应期。
- 案例本只把 `method: 'qimen-first'` 的记录计入规则 7 命中，v2.0 四法等权的记录不混入。

## 规则 8　类神入传（判「事是否成形／发生」）
- 类神按占类：求财、股市＝财爻、青龙；事业＝官鬼；学业＝父母（印）、朱雀；婚姻＝六合、天后、青龙；
  行人、寻人＝六合；怀孕＝子孙、六合。其余占类弃权。
- 六壬：类神入三传且不空 ＋；入传而落旬空 －（虚）；只在四课未入传 〇（酝酿）；课传皆不见 －（事未形成）。
  依据：伍剑虹《大六壬精义讲解》「三传出现则事已发生或将发生，仅在四课则在酝酿，四课也不见则事未形成」。
- 奇门：用神宫（照五行推理 v1 取用）空亡、入墓、击刑、门迫任一 －；否则旺、相 ＋；休、囚、死 〇。
- **计分对「实况是否发生」，不对如愿**：问怕发生之事时，+1 是坏消息。

## 规则 9　贵人互参（只用于事业、学业、官司、求财）
- 六壬：贵人所乘支落日旬空，或贵人临地盘辰、戌（坐狱） －；否则 ＋。依据：王雷之《实占百例》仕途、借贷各章「贵人空亡事难期」「两贵坐狱难干贵」。
- 奇门：值符落宫空亡、入墓、击刑、门迫任一 －；否则 ＋。

## 规则 10　我彼双读（所有占类）
- 六壬：干上神（第一课上神）对支上神（第三课上神）。六合、相生、比和为吉；六冲、相刑、相克为凶；
  只吉 ＋，只凶 －，吉凶并见（如子丑、卯戌合中带克，巳申合中带刑克）〇。
- 奇门：我宫（转盘日干宫、飞盘年命宫，照五行推理 v1）对时干宫：同宫、比和、相生 ＋；相克 －。
- 提醒：奇门「日干—时干生克」单独测过只有 52.5%，已淘汰；本条要两边同向才投票。
